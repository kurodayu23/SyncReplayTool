# 数据同步工具（SyncReplayTool）

把本机一个文件夹里的数据，通过 SSH + rsync 投递到另一台电脑的指定目录。

支持 Windows x64 与银河麒麟 x86_64。接收端不装本软件。

## 接收端要准备什么

数据是从**发送端电脑**传到**接收端电脑**的。以下几件事都要在**接收端那台机器**上做，需要接收端的人配合。

1. **开 SSH 远程登录**
   银河麒麟一般在「设置 → 系统 → 网络 → 远程登录」里打开，或由管理员执行：

   ```bash
   sudo systemctl enable --now sshd
   ```

   没开这个，软件无论怎么配都只会报连不上。

2. **装 rsync**
   银河麒麟桌面版一般自带。若提示 `rsync: command not found`，请接收端管理员执行：

   ```bash
   sudo apt install rsync
   ```

   发送端软件包内自带一份 rsync，但那只管发送这一侧；接收端那一份必须由接收端自己提供。

3. **要一个账号，且该账号对落盘目录有写权限**

   请接收端的人提供：接收端 IP、登录账号与登录密码（或一对 SSH 私钥）、SSH 端口（默认 `22`，对方改过才需要填）、以及数据要落到哪个目录（该账号必须能在里面新建和修改文件）。

4. **两台电脑之间 SSH 端口要能连通**

   不要求在同一个网络或同一个局域网，只要接收端的 SSH 端口从发送端能访问到就行。跨公网时两端都在 NAT 后，需要 VPN 或端口映射，本工具没有内网穿透能力。

   判断方法：在发送端试连接收端的 IP 和端口，能连上即可。

   **不要用 ping 判断** —— 很多网络禁 ping 但 SSH 端口是放行的，ping 不通不代表传不了。

## 发送端怎么用

1. 解压（Windows 直接解压，麒麟执行 `tar -zxvf 数据同步工具-麒麟.tar.gz` 后 `cd srt-client`）
2. Windows 双击 `SyncReplayTool.exe`；麒麟执行 `sh run.sh`
3. 点右上角齿轮打开【传输与工具设置】，填本机目录、目标 IP、SSH 端口、账号密码或私钥、目标落盘路径
4. 点「**测试网络连接**」，确认显示连接成功
5. 点「**保存设置**」，软件随即扫描本机目录生成文件清单
6. 勾选要传的文件，点右下角「**开始同步**」

麒麟首次启动如果安全中心弹出「阻止非法应用程序执行」或提示未授权的 `libQt5xxx.so`，请全部选择「始终允许」。

### 工具调用列

表格最右侧的「工具调用」列可以为不同文件后缀指定用哪个软件打开。规则表里只填工具的 exe 路径即可，参数留空时软件会自动把待打开文件的路径追加进去。

按钮按该行配置的工具有几个分级显示：1 个工具直接显示工具名；2 个工具显示两个按钮；3 个及以上显示「打开」+「更多」，「更多」里是完整列表。

## 传输过程中状态怎么读

| 状态 | 含义 |
| --- | --- |
| 已完成 | 该文件已完整传到接收端 |
| 远端已有 | 接收端已有同名同内容文件，本次没有重复传输 |
| 失败 | rsync 报了该文件的错，日志里有对应的失败原因 |
| 已取消 | 传输过程中点了取消 |

传输失败时，程序已传输的部分留在接收端的 `.srt-partial/` 目录下，**没有以原文件名落盘**，下次同步会因为大小不一致自动重传，不需要手动删除。

## 排障：日志里的责任归因

传输或连接受阻时，日志会直接标明责任主体和处置动作：

| 责任方 | 典型特征 | 处置 |
| --- | --- | --- |
| 本机（发送端） | 源文件被移走、本地磁盘满、私钥权限过宽、安全软件拦截子进程 | 核对源文件；把软件与 rsync 加入白名单 |
| 网络链路 | IP 填错、防火墙丢弃 SSH 端口 | 核实端口；试连接目标 IP 的 SSH 端口；联系管理员放行 |
| 身份认证 | 账号密码不符、公钥未登记到 `authorized_keys` | 核对账号与密码大小写；检查密钥匹配 |
| 接收端 | `No space left on device`、`Permission denied`、未装 rsync | 通知接收端负责人清理磁盘、赋权或安装 rsync |

## 配置隔离

配置文件位于 `%APPDATA%\AP\SyncReplayTool.ini`（麒麟为 `~/.config/AP/SyncReplayTool.ini`），保存在当前用户目录下，**不会**被本工具当作数据文件同步到接收端，也不会串到别人的机器上。

## 从源码构建

Qt 5.9.6 + qmake。

```powershell
qmake SyncReplayTool.pro
jom
```

Linux 同理（`qmake && make`）。

Windows 下 `scripts/build-win.ps1` 打包发布版：脚本里的本机路径（Qt 安装位置、MSVC、SDK）需要按自己的环境调整。
